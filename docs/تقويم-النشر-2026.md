## 4) إشارات الخطر (لو ظهرت، غيّر الخطة)

## 5) الأرشفة (كل حلقة)

```
episodes/NN-الاسم/
  scenes.json          ← النص + البرومبتات (المصدر)
  publish.md           ← بيانات النشر
  assets/audio/...     ← الصوت الأصلي + المعاد توقيته
  assets/images/...    ← الصور + الثامبنيلز
output/dl/             ← mp4 + zip + الشورتات (مش في Git — كبير)
```

**قاعدة:** أي حلقة لازم تقدر تعيد رندرها بأمر واحد بعد سنة. لو مش قادر، الأرشفة ناقصة.
