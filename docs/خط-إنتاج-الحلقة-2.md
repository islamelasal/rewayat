## 1. الفصل بين السرد والحوار والمؤثرات

الحلقة الأولى كانت **سرد واحد** (طارق يحكي). الحلقة التانية **حوار درامي**، فكل مشهد
مقسوم لمقاطع مستقلة، كل مقطع له متكلم وملف صوتي منفصل وتوقيت حقيقي:

```json
"segments": [
  {"kind": "narration", "speaker": "ياسين", "text": "...", "audio": "assets/audio/ep02/tts/s01-1.mp3"},
  {"kind": "dialogue",  "speaker": "فؤاد",  "text": "...", "audio": "assets/audio/ep02/tts/s01-2.mp3"}
]
```

| العنصر | مين بيعمله | إزاي |
|---|---|---|
| **السرد** | ياسين (voice-01) | `kind: narration` — يظهر كلون أبيض عاجي |
| **الحوار** | فؤاد (voice-02) | `kind: dialogue` — يظهر **أزرق فاتح** + اسمه فوق السطر |
| **المؤثرات** | `pipeline/sfx.py` | `sfx_ar` لكل مشهد — نغمي فقط، بدون نويز |
| **المزيكا** | `pipeline/audio.py` | `music_ar` — درون متغيّر حسب `mood` |

الفصل ده مش شكلي: الترجمة بتتقص على **توقيت كل مقطع بالمللي ثانية**، مش توزيع
متساوي على الزمن. النتيجة إن كل سطر يظهر بالظبط وهو بيتقال.

## 2. ياسين = الراوي + البطل

ده أهم قرار في الحلقة، ومطبّق على 3 مستويات:

1. **الصوت:** نفس المتكلم (voice-01) في السرد وفي حوار ياسين — مفيهاش صوت تالت يشتت.
2. **الصورة:** ياسين موجود في كل مشهد، وبيتحرك في الكادر (slow push / pan) بدل لقطات ثابتة.
3. **النص:** ياسين بيحكي بصيغة المتكلم في السرد، وبيتحول لحوار في اللحظة اللي بيتكلم فيها
   بصوته — الفرق بين «بيحكي» و«بيقول» واضح في الترجمة بالاسم واللون.

قاعدة الكتابة: ياسين **ما بيرويش اللي هو بيعمله** (مفيش «فقلت له» في الحوار)،
السرد بيقف لما الحوار يبدأ، ويرجع بعده. ده اللي بيمنع التكرار.

## 5. الحماية من فشل التوليد

حصل فشل «Image generation failed» ووصلنا لحد المقطع/الصورة في الدورة. عشان مفيش
حاجة توقف التجميع:

| المخاطرة | الحل المطبّق |
|---|---|
| صورة تفشل | إعادة فورية بـ**صياغة مختلفة** (مش نفس البرومبت) |
| نص الصورة مقطوع/تالف | `pipeline/verify.py` — `im.verify()` + فحص الأبعاد |
| مقطع صوتي ناقص | `dialogue.assemble_scene` **بيتخطاه ويكمل**، والترجمة بتتظبط على الباقي |
| مقطع صامت أو قصير | الفحص بيرصد `rms < −45dB` أو `duration < 0.35s` ويحذّر |
| ملف مش موجود | تحذير واضح، مفيش crash |

```bash
python3 pipeline/verify.py episodes/02-الباب/scenes.json
```
