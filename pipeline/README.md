# pipeline — محرك إنتاج «ساعة الرمادي»

يبني فيديو 1080p كامل (حركة كاميرا + تدرّج لوني + جْرين + ترجمة عربية محروقة + ميكس صوتي)
من ملف مشاهد JSON. مفيش أي خدمة خارجية — كله محلي.

## التشغيل

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r pipeline/requirements.txt

python3 pipeline/render.py episodes/01-الرمادي/scenes.json \
  --out output/rewayat-ep01.mp4

# نسخة سريعة للاختبار (أول 15 ثانية)
python3 pipeline/render.py episodes/01-الرمادي/scenes.json \
  --out output/preview.mp4 --preview 15
```

### ضبط سرعة الإيقاع (مهم)

التعليق الصوتي المولَّد بيطلع سريع (~115 كلمة/دقيقة). الإيقاع الدرامي المطلوب **85–95**.
لتصحيحه:

```bash
python3 pipeline/retime.py episodes/01-الرمادي/scenes.json --tempo 0.86
# → ينشئ assets/audio/ep01/retimed/ و episodes/01-الرمادي/scenes-slow.json
```

`retime.py` بيعمل حاجتين:
1. **إبطاء مع الحفاظ على طبقة الصوت** (`atempo` — مش بيخنق الصوت).
2. **إطالة الصمت** عند نهايات الجمل (0.35–0.60s) والجمل الفرعية (0.18–0.26s) — ده اللي بيدّي إحساس الراوي.

بعدين ارندر بـ `scenes-slow.json`.

> ⚠️ استخدم `--tempo 0.85–0.88`. أقل من 0.80 بيبقى بطيء بشكل غير طبيعي.

## شكل `scenes.json`

```json
{
  "series": "ساعة الرمادي",
  "scenes": [
    {
      "id": 1,
      "vo": "النص اللي بيتقرأ (للعرض/الترجمة)",
      "vo_file": "assets/audio/ep01/scene-01.mp3",
      "image_file": "assets/images/ep01/scene-01.png",
      "motion": "slow_zoom_in",
      "mood": "tense",
      "chapter": "الافتتاحية"
    }
  ]
}
```

- `motion`: `slow_zoom_in | slow_zoom_out | pan_right | pan_left | push_up`
- `mood`: `tense | calm | awe` (بيتحكم في طبقة الموسيقى/النبض)
- `lead` / `tail`: ثواني صمت قبل/بعد التعليق (افتراضي 0.55 / 1.25)

## اللي المحرك بيعمله

1. يحسب مدة كل تعليق صوتي ويبني تايم لاين.
2. يبني **الشريط الصوتي** بمحرك `pipeline/audio.py` (3 مسارات): تعليق صوتي مُنظَّف + موسيقى نغمية + ducking.
3. يرندر كل مشهد بـ zoompan (حركة بطيئة جداً) + vignette + تدرّج لوني + جْرين فيلم + نبض إضاءة.
4. يدمج المشاهد مع fade in/out بينها.
5. يحرق ترجمة ASS عربية (Noto Naskh) — سطرين كحد أقصى، أسفل الشاشة.
6. يضيف كارت المقدمة/النهاية ويكتب `ep01-chapters.txt` (فصول يوتيوب).

## محرك الصوت `pipeline/audio.py`

```
التعليق (VO)  ──► highpass 85 → deesser → EQ ──► compressor ──┐
                                                              ├── ducking ──► R128 ──► AAC 256k
الموسيقى ──► EQ ──► مستوى ديناميكي ───────────────────────────┘
```

| المرحلة | التفاصيل |
|---|---|
| **تنظيف الصوت** | `highpass 85Hz` (يزيل هدير الغرفة) → `deesser` → قطع 260Hz (الخشونة) → رفع 3.2kHz (الحضور) → تلطيف 7.5kHz |
| **ضغط** | `3:1` بنسبة thresh `-18dB` — يوحّد مستوى الراوي |
| **الموسيقى** | **نغمية بحتة** (جيبية + LFO) — مفيش نويز أبيض ولا نقرات. ده كان مصدر الوشوشرة |
| **الاتساع** | Haas 14ms — قناتين مختلفتين فعلياً (مش مونو مضاعف) |
| **الميزان** | الموسيقى تُحسب **ديناميكياً** تحت الصوت بـ 13dB RMS، ثم تنخفض 11dB وقت الكلام |
| **Ducking** | منحنى من طاقة الصوت: هجوم 40ms / انفراج 700ms |
| **الماسترف** | EBU R128 موجة كاملة: **-16 LUFS / -1.5 dBTP / LRA 11** (معيار يوتيوب) |

القياسات على الميكس النهائي: ستيريو (ارتباط القناتين **0.97**)، عمق الداكنج **~25dB**،
سكوت **-43 dBFS** (نغمي، بدون وشوشرة).

```bash
# اختبار الشريط الصوتي لوحده على المشاهد الثلاثة الأولى
python3 pipeline/audio.py episodes/01-الرمادي/scenes-slow.json --out /tmp/mix.wav --stems
```

## ملاحظات تقنية مهمة

- **الترجمة**: استخدم خط **Noto Naskh Arabic** أو **Noto Kufi Arabic** (موجودين في `assets/fonts`) مع **Spacing = 0**.
  خطوط Cairo/Google Sans بتطلع الحروف المركّبة (لا/لأ) مربّعات في libass لأن shaping بتاعها مختلف.
- **العربية**: اكتب النص خام في الـ ASS؛ libass بيعمل التشكيل والترتيب بنفسه. متعملش reshaper/bidi مسبقاً
  (ده بيعمل عكس مزدوج).
- **الستيريو**: `amix` + `pan` في ffmpeg كانا بيرجّعوا الميكس لمونو (ارتباط 1.000).
  الحل: الدمج والـ ducking بيتمّوا في **numpy** (`mix_and_master`)، وffmpeg للترميز بس.
- **`loudnorm` في سلسلة فلاتر** بيقلب معدل العيّنة لـ 192kHz/مونو ويخرّب الميكس —
  لازم `-ar 48000` و`-ac 2` صريحين.
- قابلية التوسّع: زوّد مشاهد في `scenes.json` وملفاتها في `assets/` — مفيش تغيير في الكود.

## مؤثرات الصوت `pipeline/sfx.py`

المؤثرات **نغمية بالكامل** — مفيش نويز أبيض ولا نقرات (دي كانت سبب الوشوشرة في النسخة الأولى).

| المؤثر | التركيب | فين بيستخدم |
|---|---|---|
| `wind` | ثالوث 55/82.5/110/137.5Hz + تنفّس بطيء + انزلاق ترددي | الافتتاحية، الطريق |
| `thunder` | هبوط 62→31Hz + هارمونيات + 12 كراكل نغمي + رنّة | الانفجار، الملحمة |
| `drone` | 41.2/55/82.5Hz بهجوم 50ms وذيل 2.4s | اللحظات المفصلية |
| `bell` | 196/294/392/588/784Hz بنسب تخميد مختلفة | مشاهد الرهبة |
| `radio` | حاملات 420–1180Hz بتقطيع وانزلاق | مشاهد الراديو |

**الميزان:** المؤثرات بتدخل −25 لـ −34 dB، وبتنخفض 7dB وقت الكلام
(الموسيقى بتنخفض 11dB) — عشان الحدث يبان من غير ما يغطّي الراوي.

```bash
python pipeline/sfx.py episodes/01-الرمادي/scenes-slow.json --out /tmp/sfx.wav
```

## الشورتات `pipeline/shorts.py`

```bash
python pipeline/shorts.py output/dl/الحلقة.mp4 <ملف ASS> --outdir output/dl/shorts
```

- 3 مقاطع 1080×1920 (أول 50–60 ثانية من نقاط مختارة).
- **بيقصّ 12% من أسفل المصدر** عشان الترجمة المحروقة الأصلية متظهرش مرتين.
- الترجمة بتتحرك لـ y=1420 (منطقة آمنة فوق واجهة يوتيوب).
- كوفر 1080×1920 لكل شورت بـ `make_thumb.py --size 1080x1920`.

## ملاحظات على الانتقالات

- `xfade` بين المشاهد مدته 0.65s — لازم **تطويل كل مقطع** بنفس المدة (إلا الأخير)
  وإلا المدة الكلية تنقص والترجمة تتقدّم عن الصوت.
- الكود بيعمل ده تلقائياً عبر `sc["_pad"]`.
